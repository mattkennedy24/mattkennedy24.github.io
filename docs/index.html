03 — Featured project Beta

Ask GM

An AI chess coach. Ask grandmasters about the position on your board.

Ask GM is in private beta. Request a beta code and I’ll email it to you.

Request beta access Open the app (beta code required) →

Ask GM is a chess coaching web app. You play a game or study an opening, and you can ask questions about the position to AI versions of Magnus Carlsen, Hikaru Nakamura or Bobby Fischer. Each one answers in their own voice. The coaching is backed by a real chess engine running in your browser, so the advice reflects the actual position, not the model’s guesses.

Ask GM is an independent project. The grandmaster personas are AI-generated and are not affiliated with or endorsed by Magnus Carlsen, Hikaru Nakamura or Bobby Fischer’s estate.

  • 3AI grandmasters
  • 467unit tests
  • 50+openings, engine-checked

What it does

  • Play and analyse: Move pieces by clicking or dragging. Stockfish runs in the browser and shows the evaluation and the top three lines, and you can preview any line on the board.
  • Talk to a grandmaster: Ask anything about the position and get a conversational reply. Moves in the reply can be clicked to play them, and suggested follow-up questions keep the conversation going. Each grandmaster keeps their own conversation, and starting a new game starts a fresh one.
  • Move-by-move review: Every move gets a verdict (best, good, inaccuracy, mistake, blunder), worked out from the engine’s evaluations before and after it. Import a game as PGN and it’s reviewed move by move, then summed up.
  • Opening lessons: A searchable library of annotated openings and variations with auto-play. Every line is checked by Stockfish.
  • Stays in character: Off-topic questions get a short, funny brush-off from the grandmaster.

How it’s built

  • Frontend: React, TypeScript and Tailwind, with a custom “newspaper games page” design system (paper and ink, two typefaces, no shadows). Built for laptops and iPhones.
  • Backend: Node/Express API calling Anthropic’s Claude, deployed on Railway.
  • Engine: Stockfish compiled to WebAssembly, with a second background engine that reviews the moves you’re not looking at.

Technical highlights

  • The coach is grounded in facts: Before the model sees a question, the server computes facts about the position: which pieces can be won by exchanges, pawn structure, king safety and the game result. The model explains the position; it doesn’t have to work it out.
  • Browser input isn’t trusted: The server replays the move list itself, accepts only a fixed vocabulary for move verdicts, and validates every field before it reaches the prompt.
  • Tested end to end: 467 unit tests, Playwright browser tests on laptop and phone screen sizes, and scripted Stockfish checks of every opening line and of the coach’s tactical claims.
  • Design rules enforced by tests: The build fails if a component uses a colour, font size or style outside the design system.
